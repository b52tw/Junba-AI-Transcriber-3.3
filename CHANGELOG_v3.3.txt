峻爸 AI Transcriber v3.3 — 最佳化核對版

1. 新增「使用方式」：最佳化（推薦）/ 完全離線穩定 / 線上 Gemini 快速 / 進階自訂。
2. 最佳化為預設：有 API Key 自動混合模式；無 Key 自動完全離線。
3. 新增自動切段策略：最佳化 + 0 分鐘時依音檔長度、硬體與模型自動選 3/5/10/15 分鐘。
4. 舊款 Intel Iris Xe/UHD/HD 顯示晶片採保守路線：自適應優先 CPU，模型 small/medium，降低 OpenVINO 大模型長時間停在 35% 的風險。
5. 硬體學習加入 RTF（處理耗時 / 音訊長度）紀錄；同一台電腦會逐次學習哪條路徑較快。
6. 加入音檔相容預檢；無法解碼/無法判讀長度的檔案自動轉為 16kHz mono PCM WAV 後再處理。
7. 新增錄音核對播放器：HTML + VTT。點逐字稿可跳轉錄音時間，播放時自動跟隨反白，並可搜尋文字。
8. 核對播放器若原音檔移動，可在 HTML 直接重新選擇音檔。
9. 混合模式 Word 同時輸出 Gemini 整理後全文與時間軸逐字稿，避免整理稿與字幕核對互相覆蓋。
10. 介面顯示維持「峻爸」，內部識別維持 Junba 相容舊設定。
