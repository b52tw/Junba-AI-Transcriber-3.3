2. 最佳化 + 切割 0 分鐘 = 自動切段；長錄音不再預設整支一次推論。
3. 舊款 Intel Iris Xe/UHD 初次自適應優先 CPU INT8，模型 small/medium；Intel Arc / CUDA 維持較高效能路線。
4. 每台電腦獨立累積實測 RTF（耗時/音訊秒數），後續自適應依真實速度調整。
5. 音檔開始前做 FFmpeg 相容檢查；異常容器/編碼自動轉 16kHz mono PCM WAV。
6. 預設建立 HTML + VTT 錄音核對播放器；點逐字稿可跳時間，播放時會反白段落。
7. 混合模式 Word 同時保留 Gemini 整理稿與時間軸逐字稿。
